APEXHR NEXUS — ANIMATED EMPLOYEE MANAGEMENT SYSTEM
===================================================

FILES
- index.html     Main dashboard
- employee.css   Premium styling and CSS animations
- employee.js    Employee directory functionality
- README.txt     This guide

HOW TO RUN
1. Extract the ZIP folder.
2. Keep all three project files in the same folder.
3. Double-click index.html to open it in Chrome, Edge, or Firefox.
4. Internet is only needed for the optional Google Fonts; the dashboard itself runs locally.

FEATURES
- Animated ambient background, orbiting orb, glowing UI and responsive layout
- Add, edit and delete employee profiles
- Search by name, email, role, department, work mode or status
- Department and status filters, plus quick Active / On Leave / Remote links
- Dashboard totals and department composition chart update with your data
- Pagination and CSV export
- Browser localStorage saves changes on the current browser/device
- Ctrl+K (or Cmd+K) opens the quick command center
- Reduced-motion accessibility preference is respected

IMPORTANT
This is a front-end demo. Data is stored locally in the browser on this device; it is not a shared online database and does not sync between devices. Clearing browser site data may remove saved employees. Sample employee records appear on first launch.
